# Personaj rasmlari

Bu yerga Sprunki personajlarining rasmlarini qo'ying. Fon shaffof (PNG) bo'lsa eng chiroyli chiqadi.
Fayl nomi personaj nomi bo'lishi kerak:

```
oren.png      raddy.png      black.png
oren_2.png    fun_bot.png    mr_tree.png
```

Ssenariyda shu personaj tilga olinsa, AI rasm o'rniga sizning rasmingiz ishlatiladi.
Bitta personajga bir nechta rasm qo'ysangiz (`oren_2.png`, `oren_3.png`), tizim ular orasidan tasodifiy tanlaydi.
